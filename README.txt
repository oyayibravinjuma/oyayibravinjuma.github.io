OYAYI BRAVIN JUMA — WEBSITE PACKAGE

FILES
- index.html: complete responsive one-page website
- styles.css: design and mobile layout
- script.js: mobile navigation and current year
- assets/waks-na-kazi-award.jpg: supplied award photograph
- assets/favicon.svg: site icon
- robots.txt and sitemap.xml: basic search-engine discovery files

PUBLISHING
1. Keep the folder structure unchanged.
2. Upload the contents of this folder to the public web root (often public_html) of your hosting account.
3. Connect oyayibravinjuma.com to that hosting account and enable HTTPS/SSL.
4. Check that https://oyayibravinjuma.com/ loads on mobile and desktop.
5. Verify the domain in Google Search Console, then submit https://oyayibravinjuma.com/sitemap.xml.

IMPORTANT
This package is a finished static website, but it is not live on the internet until you upload it to a hosting provider and connect the domain. Replace or supplement the award photo with a dedicated professional portrait if desired. Confirm all biographical details and obtain permission before publishing photographs of other people. Book titles are labelled as projects because publication status has not been confirmed. No unverified social-media profiles have been added.
